    如何连接移动电源
    1. 使用支持数据传输的 USB-C 线连接移动电源与电脑。
    2. 使用桌面版 Chrome 或 Edge 打开本页面，点击“连接移动电源”。
    3. 在浏览器提示中允许访问设备，并保持页面打开直至读取完成。
    如果页面一直未发现设备，请更换数据线或 USB 接口后重试。手机浏览器、Safari 和 Firefox 当前不支持本页使用的 Web MIDI 连接方式。
